## 1. 调研目标

回答四个问题，作为产品需求与排期的依据：

1. **市场规模与时机**：餐饮数字化/餐饮 SaaS/本地生活/团餐各赛道的规模、增速、渗透率还有多少窗口？
2. **竞争格局**：闭源 SaaS、平台生态、开源同类各自占位如何？本产品在哪个生态位？
3. **用户与场景**：谁会部署这套系统？他们的核心任务（JTBD）与产品模块如何对应？
4. **差距与风险**：相对市场主流缺什么？做这件事有哪些外部风险？

## 2. 宏观市场（2024–2026）

### 2.1 餐饮大盘

- 2025 年全国餐饮收入同比增长 3.2%（毕马威《2026 中国餐饮企业发展报告》），增速放缓，**下沉市场成为增长亮点**，行业主线从扩张转向「精细化管理 + 数智化降本」。
- 连锁化率持续提升：2018 年 12% → 2025 年 23%（知乎 2026 行业排名文口径）～ 25%（竞析报告口径）；小吃快餐占连锁门店约 43%。连锁化直接驱动「总部—门店管控、加盟分账、多店报表」需求。

### 2.2 餐饮数字化 / SaaS

| 指标 | 数据 | 来源 |
|---|---|---|
| 餐饮商户数字化渗透率 | **62%**（2026） | 博客园 2026 收银系统盘点 |
| 市场定性 | 百亿级（人民币）；奥琦玮创始人称「餐饮数字化将三分天下（软件/硬件/服务）」 | 亿欧访谈 |
| 增速 | 收银系统市场年复合 **18%+**，需求从单一收银转向一体化数智化 | 同上 |
| 中美对比 | 美国 SaaS 渗透率 70%+，中国约 15%——垂直 SaaS 仍在高速渗透期 | 客如云官网 |
| 结构性判断 | 前端（点餐/支付 91.7%）渗透充分；**后端（供应链数字化 45%）与 AI（渗透率约 15%）仍在早期** | 竞析报告 §3.1 |

> 口径提示：竞析报告「餐饮数字化市场 2026 破千亿、餐饮 SaaS 2025 约 320 亿」与「百亿级」定性一致，可并用。

### 2.3 本地生活 / 到店 / 外卖平台

- **抖音生活服务**：2025 年支付 GMV 超 **8500 亿元、同比 +59%**；2026 年增速目标约 50%、全年有望破 **1.2 万亿元**，目标与美团到店拉平；中小商家动销门店累计超 912 万家；核销率约 57%；到店业务线上化率仍在个位数（36氪/雷峰网、虎嗅 2026 报道）。
- **外卖佣金**（2026 新口径，与竞析报告的 20–25% 综合口径并存）：
  - 名义平台佣金：美团 **6–8%**（费率透明化后拆分为技术服务费+履约服务费）、饿了么 **5–8%**、京东外卖初期承诺 ≤5%；
  - 商家实际综合成本（含平台配送、流量投放、营销活动）普遍 **15–20%+**，2025 年五部门因此约谈各平台（新华报业）。
  - **对私域自建的启示**：抽佣痛点依然成立，但「名义费率」在下降，自建外卖的卖点要讲「综合成本 + 数据自主」，不能只讲佣金数字。
- **第三方小程序 SaaS 也抽佣**：市面点餐小程序平台抽取订单 10–30%（东方财富 2026 对比文）——**自建开源系统连这层也省掉**，这是比「对抗美团抽佣」更直接的差异化卖点。

### 2.4 团餐 / 智慧食堂（相邻市场）

- 市场规模：2024 年约 2.7 万亿元，2026 年预计 3.5 万亿+（艾瑞《2025 团餐行业报告》/FoodTalks），增速高于餐饮整体；中国烹饪协会口径 2025 年 2.2 万亿（统计口径不同）。
- **数字化渗透率仅 20.7%**（中国烹饪协会 2025 报告）——后端数字化的最大洼地。
- 监管趋严：2025 年市场监管部门检查集中用餐单位 57.54 万家次、2026 年截至 7 月罚没 5541 万元（知乎/监管动态），合规压力倒逼食堂数字化。
- **与本产品的接口**：已有企业餐补（subsidy）模块；「团餐档口/智慧食堂」是天然相邻扩展方向（当前未规划，仅登记）。

### 2.5 AI 与私域（能力型趋势）

- AI 已从概念进入落地：麦当劳 AI 点餐客单价 +4.5%、订单/点餐准确率 +17/+13pct（36氪《中国餐饮 AI 应用研究报告 2026》）；订单预测（减少食物浪费/备货）与 AI 排班（人效）是被实践验证的两大场景；客如云 2026 战略「AI+生态」**免费开放五大智能体**（中国日报）。
- 私域：公域获客成本持续走高，2026 年私域经营进入深化阶段；有赞/微盟「三店一体」仍是中大型品牌溢价模式（会员外卖单均约为平台单 3 倍）。
- **对本产品的压力**：头部厂商 AI 能力正在免费化下沉，开源方案必须靠「可接自选大模型、数据不出店」保持 AI 叙事的差异化。

## 4. 闭源竞品档案（四类玩家）

> 详细厂商矩阵（定位/部署/收费/能力）沿用竞析报告 §1，本节只登记 2026-10 检索到的**增量信息与口径修正**。

### 4.1 平台型

- **美团收银**：软件端已定位「免费」（配合收银一体机硬件收费，官方 rms.meituan.com）——与竞析报告「月费 298–698 元」为不同时期/套餐口径，对标时以官方最新报价为准。外卖端 2021 年起费率透明化（技术服务费 6–8% + 履约费拆分）。
- **饿了么/Napos（阿里）**：淘宝+支付宝双流量，AI 菜品分析「饿小味」。
- **抖音生活服务**：2026 年开放能力已覆盖到店餐饮点单/核销/会员（developer.open-douyin.com）；「抖省省」上线直接对标大众点评。**餐饮商家多平台经营已成常态**——聚合对接的市场价值随抖音 GMV 放大而上升。

### 4.2 独立 SaaS

- **客如云**：软件年费约 **3000–5000 元**（2025 官网资讯页），3 年期合约下浮 15–20%；2026 战略「AI+生态」，免费开放五大智能体 + 智能选址数据。
- **哗啦啦**：2023–24 资金链/提现危机（行业整合信号：SaaS 持有商家资金有信任风险）→ 对本产品的启示：**结算资金链路透明可审计是开源自建的优势叙事**。
- 天财商龙/奥琦玮/二维火/美味不用等：见竞析报告 §1.2，无重大增量。

### 4.3 私域电商延伸型（有赞/微盟）与聚合类（思迅/企迈）

- 定位与收费沿用竞析报告（有赞外卖通 300 元/店/年；微盟 6800–29800 元/年）。
- 聚合类的「私有部署 + 多平台聚合」路径与本产品开源禀赋最相近，是**定位上最直接的闭源对标**。

## 5. 开源同类竞品（本次调研新增，竞析报告完全缺失的一块）

### 5.1 国内（Gitee 生态）

| 项目 | 形态 | 与本产品对比 |
|---|---|---|
| **瑞吉外卖**（黑马教学项目谱系） | Spring Boot + Vue 单体，管理/用户/骑手三端 | 本项目的谱系起点（教学级单店原型）：无多租户、无 AI、无平台对接、无团餐/餐补/进销存等经营深度。本产品 = 该原型向商业化 SaaS 的全量重写（Boot 4/JDK 25、41 模块、1064 测试） |
| **yshop-drink 意象桌面** | Spring Boot 3 + OAuth2 + MP + Vue3 + UniApp 扫码点餐 | 聚焦茶饮扫码点餐细分；无外卖履约/经营报表纵深 |
| **linmour 扫码点餐** | Java 多租户 SaaS，多商户独立小程序 | 与本产品同样主打多租户，但范围限于扫码点餐场景 |
| **woniu-bee** | 餐饮点餐小程序（点餐/外卖/排队/扫码/支付） | 单店小程序级，无后台经营体系 |
| **暹罗点餐（多门店连锁版）** | Java 四端（用户/商家/配送/管理） | 连锁单模板交付型，社区与文档深度有限 |

**结论**：国内开源同类多为「单场景模板」（扫码点餐/小程序点餐）或「教学原型」，**尚无一个覆盖「多租户 + 三端 Web + 三端小程序 + 配送履约 + 进销存/成本/财务 + AI + 平台对接」全链路的开源项目**——本产品的生态位。

### 5.2 海外

| 项目 | 形态 | 启示 |
|---|---|---|
| **TastyIgniter**（PHP/Laravel） | 海外最成熟的自托管点餐系统，官方口号「无平台费、无月费」 | 验证「自建免佣」需求全球存在；PHP 栈对国内 Java 生态无直接竞争 |
| **KitchenAsty**（2026 新，MIT） | TypeScript monorepo，定位开源版 Toast/Square | 新玩家仍在入场，说明赛道热度；现代化栈值得观察 |
| **GloriaFood 关停事件** | 此前流行的免费点餐 SaaS 已停服（Fleksa 2026 盘分区「after gloriafood」） | **免费闭源 SaaS 停服风险的真实案例**：商家数据与入口一夜失效——自托管开源的抗风险卖点有实证 |

### 5.3 相对开源竞品的差异化主张

① 全链路广度（41 模块 vs 单场景模板）；② 中国市场本地化（微信 JSAPI 支付、小程序三端、美团/饿了么对接、企业餐补/发票合规）；③ 工程质量（1064 测试、Flyway 基线、安全纵深：BCrypt/Jasypt/限流/防盗刷三层）；④ 技术栈前沿（Boot 4 + JDK 25 + 虚拟线程 + Jackson 3，对二开者有吸引力）。

## 6. 成熟产品能力对标（2026-10-24 补充检索，→ 优化项映射）

> 逐能力对标「市场上成熟产品实际在卖什么」，并把差距映射为 功能升级.md 的优化登记项（O-16～O-20）。对标对象：客如云智享版、美团收银、Toast/Square（海外）、金蝶星空餐饮云、有赞/天财商龙营销玩法。

| 能力域 | 成熟产品怎么做（来源） | 本项目现状 | 差距 → 优化项 |
|---|---|---|---|
| 收银 POS | 客如云智享版：点餐收银/外卖团购/会员营销/报表一体，主打**弱网离线稳定不漏单**（离线登录/开台/打印/结账）；快餐场景打通点餐→收银→**叫号取餐**→KDS，AI 智能秤降排队（[客如云官网](https://www.keruyun.com)、[智享版](https://www.keruyun.com/news/3904.html)） | 收银台三区定式 + 日结条 + 多支付方式已落地（UI设计.md §3.5） | Web 端整页依赖网络，无离线兜底 → **O-19**；叫号取餐/智能秤属硬件场景，未登记 |
| 接单聚合 | 美团收银背靠外卖/团购生态，「外卖接单整合」是其最强卖点；快餐收银对比把「外卖团购能否**同屏接单**」列为核心维度（[美团收银官网](https://rms.meituan.com/shouyin/retail)、[CSDN 对比](https://blog.csdn.net/2601_96291641/article/details/165879180)） | 自有订单（order 模块）与平台订单（platform 模块）**分页分列**，接单员需切页 | 订单列表聚合平台单 + 来源标识 → **O-16**（P1，最值得先做） |
| KDS 后厨 | 客如云 KDS 与点餐/收银/叫号链路打通；Toast KDS 为标配云能力（Chowly/Katalyst 对比） | kds 模块已有工单看板与流转 | 联动深度未逐一查证，暂不登记（待评估） |
| 供应链/进销存 | 金蝶星空餐饮云：营业大数据 + 集团管控规则的供应链模型（[金蝶](https://www.kingdee.com/products/galaxy_restaurant.html)）；智能补货实践 = 实时库存监控 + **需求预测** + 自动生成补货计划（[CSDN](https://blog.csdn.net/m290345792/article/details/137665968)） | inventory 已有智能补货（近 7 天销量估建议量、一键生成采购草稿） | 补货从销量统计升级为预测驱动（复用 report 增强预测）→ **O-20** |
| 会员营销 | 有赞复购三技巧：价格锚定/积分返利/**充值券**（[有赞 2026](https://www.youzan.com)）；天财商龙：储值难做，用**权益卡**替代；许爷剁椒鱼头**付费券包** 3 个月 26.5 万会员、单月收益 141 万（[知乎案例集](https://zhuanlan.zhihu.com/p/538051107)）；2026 方向 AI+SCRM 分层触达 | member 已有券/储值/积分/等级/营销活动，玩法为「满减/折扣/买赠/秒杀/新客」 | 付费券包（多张小额券打包售卖）与权益卡两种预付费形态未支持 → **O-18** |
| 员工管理 | 2026 收银测评标配维度：员工账号不限量、岗位分级权限、**提成管理**（[测评文](https://www.poso2o.com/articles/restaurant-pos-guide-2026.html)） | sys 已有员工/角色/部门/批量导入/工牌二维码，attendance/schedule 有考勤排班 | 提成管理缺失 → **O-17** |
| 海外参照 | Toast：**零佣金自营线上点单**（add-on）、loyalty 融入 POS 下单流、tip pooling 提成分摊（Chowly/Certus 对比）；Square：轻量按需付费 | 小程序自建点餐 = 天然零佣金（比 Toast add-on 更彻底）；会员体系已有 | 小费文化/tip pooling 属海外场景，不登记；「零佣金自营」叙事与本项目卖点一致，直接采用 |

## 7. 功能对比矩阵重评（竞析旧口径 vs 当前实测）

> 竞析报告 §2 矩阵中「Xinfei」列为 2026-10-22 之前旧口径；「当前实测」列以 `docs/模块与接口.md`（40 业务模块 / 110 Controller / 875 端点）与 PRD §5 为准。

| 对比维度 | 竞析旧口径 | 当前实测（2026-10-24） | 剩余差距性质 |
|---|---|---|---|
| 多租户 SaaS 能力 | ❌ 无 | ✅ 租户插件自动注入、总部—门店层级、多店看板、企业餐补 | 基本补齐；加盟分账等深度模型未见 |
| 平台对接 | ❌ 无 | ⚠️ 美团/饿了么双向同步 + 微信小程序三端 | **抖音生活服务未接**；在抖音 2026 GMV 目标 1.2 万亿的背景下，此缺口的市场权重在上升（升格讨论建议见 §9） |
| AI | ❌ 无 | ✅ 对话/点餐助手/经营分析/RAG/多供应商 | 头部 AI 免费化（客如云智能体）挤压，须强化「自选模型+数据不出店」叙事 |
| BI/报表 | ⚠️ 基础 | ✅ 日报/销售/时段/排行/支付/增强预测 + 成本 + 导出 | 自助式 BI 深度不及头部 |
| 会员私域 | ❌ 无 | ✅ 会员/等级/积分/储值/券/营销/收藏常购/触达 | 企微 SCRM 未做 |
| 硬件 | ⚠️ 上传 | ✅ 打印任务/模板、KDS | 无硬件抽象层 |
| 移动端 | ⚠️ 仅 H5 | ✅ 三端小程序 + H5 | 后台完整小程序明确不做 |
| 开放 API/生态 | ❌ | ❌ 未做 | **真实差距**（P2） |
| 云原生 | ❌ 单体 | ⚠️ 单体 + 虚拟线程（既定架构决策） | **真实差距**（P2） |
| 等保/信创 | ❌ | ⚠️ 有安全纵深（加密/脱敏/限流/安全头），无认证适配 | **真实差距**（P2） |
| 支付 | 模拟 | ✅ 微信 JSAPI 全链路（mock 沙箱可用） | 真机待配（功能升级.md O-04） |

## 8. SWOT

| | 有利 | 不利 |
|---|---|---|
| **内部** | **S**：全链路广度开源无对手；工程质量与测试纵深；栈新（Boot 4/JDK 25）利于吸引二开者；数据自主 + 零许可费 + 连第三方小程序抽佣都省 | **W**：单机单体、无高并发实证；真机上线配置未完成；开源运营（社区/文档/发布节奏）刚起步；AI 深度不及头部 |
| **外部** | **O**：后端数字化（供应链 45%/团餐 20.7%）与 AI（15%）渗透洼地；平台综合成本 15–20%+ 与第三方小程序 10–30% 抽佣的避险需求；GloriaFood 关停示范闭源风险；信创/私有化刚需；抖音生态崛起带来新对接需求 | **T**：头部 AI 能力免费化下沉；平台 API 政策变动风险；微信生态依赖（支付/小程序审核）；开源被竞品直接拿去商业化（license 与生态位被稀释） |

## 9. 市场风险登记

| 风险 | 影响 | 缓解方向 |
|---|---|---|
| 微信生态依赖（JSAPI 支付、小程序审核、域名合规） | 支付/发布链路单点 | 已有货到付款/到店付兜底；支付渠道抽象在 payment 模块内 |
| 平台（美团/饿了么/抖音）开放政策与费率变动 | 对接模块维护成本上升 | platform 模块适配器化设计；对接凭证后台可配 |
| 头部 AI 免费化 | AI 差异化被抹平 | 主打「自选供应商 + RAG 私有知识库 + 数据不出店」（已具备） |
| 高并发无实证 | 连锁大客户信任门槛 | PRD §4.4「待确认」项：补压测数据后再量化承诺 |
| 开源被商业化白嫖 | 生态位稀释 | 属商业策略范畴，产品侧无动作项（登记） |

## 10. 结论 → 对需求文档的输入

1. **主线验证成立**：竞析 P0/P1 建议方向（多租户、聚合接单、AI、会员私域）已落地，与 2026-10 检索到的市场动向（连锁化、后端数字化洼地、私域深化）一致；后续以**深化现有模块**为主线。
2. **建议升格讨论（不擅自排期）**：抖音生活服务对接在 2026 市场背景下权重上升，可考虑从 P2「不做」口径中拆出来单独评估——按 功能升级.md §5 维护纪律，先经用户决策再动。
3. **相邻市场登记**：团餐/智慧食堂（渗透率 20.7% 洼地）与现有 subsidy 餐补模块天然相邻，仅登记不排期。
4. **叙事校准**：对外表述从「对抗平台抽佣」调整为「**综合成本 + 数据自主 + 连第三方小程序抽佣都省 + 闭源停服风险免疫**」（有 2026 数据与 GloriaFood 案例支撑）。
5. 以上结论均不改变 PRD §5.3 与功能升级.md §4 的当前口径；变更须走功能升级.md §5 维护纪律。
