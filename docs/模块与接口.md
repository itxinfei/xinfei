# 模块清单与 API 端点

**范围**：`src/main/java/com/xinfei/module/` 下 **40 个业务模块、109 个 Controller、874 个端点方法**。

**口径**：2026-10-16 由注解实测重建——遍历 `src/main/java/com/xinfei/module/**/*Controller.java`，逐文件解析类级 `@RequestMapping` 基路径 + 方法级 `@(Get|Post|Put|Delete|Patch|Request)Mapping`，一条方法级映射计一个端点；模块 = `com/xinfei/module` 下目录数，Controller = 该目录树内 `*Controller.java` 文件数。每条可回溯源码复核（测量脚本留在本地 `docs/tools/`，按 `.gitignore` 的 `tools/` 规则不随仓库发布，故此处直接给出可复算的口径定义）。

**端点说明**：取自方法上的 `@Operation(summary = "…")`（874/874 全覆盖，与 `swagger-ui.html` 展示一致）；无摘要时回退 Javadoc 首行，再回退方法名。

**路径前缀实测分布**：

| 前缀风格 | Controller | 端点 |
|---|---|---|
| `/api/**` | 59 | 348 |
| 裸业务根（如 `/order`、`/dish`） | 35 | 405 |
| `/admin/**` | 6 | 46 |
| `/sys/**` | 6 | 38 |
| `/cs/**` | 2 | 31 |
| `/front/**` | 1 | 6 |

> 根包 `com/xinfei/controller/` 已完全清空——员工、订单、菜品、分类等核心业务全部下沉到 `module/*`。
>
> **2026-10-16 重写**（旧版 2026-09 口径已全部作废）：旧版自称 36 模块 / 73 Controller，与代码不符——
> `franchise`、`retention`、`customer-service` 三个模块名在代码中不存在（`franchise` 一节还虚构了 6 个 `/api/franchise/*` 端点，实体、表、Controller 三者皆无），
> 缺 `customer`/`favorite`/`groupbuy`/`invoice`/`kds`/`subsidy`/`withdraw` 7 个真实模块，11 个模块的 Controller 数过时，
> 总览行合计（81）与头部自称（73）自相矛盾；旧版声称的 `/backend/**` 接口前缀在当前代码中 0 命中（`src/main/java` 全量 grep 无 `"/backend` 起始的映射路径），仅前端静态资源目录叫 `backend/`。

## 前缀约定观察（技术债，2026-10-16 实测复核）

1. **同一模块混用多种前缀风格**（12 个模块）。这是"新模块走 `/api/**`、老模块保留裸根"两条路线并存的结果，收敛前勿假设模块内路径同构：

| 模块 | 混用风格（Controller 数） |
|---|---|
| ai | /api ×2 · /admin ×3 |
| common | 裸业务根 ×2 · /api ×1 |
| delivery | /api ×10 · 裸业务根 ×2 |
| dining | /api ×7 · 裸业务根 ×1 |
| dish | 裸业务根 ×3 · /api ×1 |
| marketing | /api ×1 · 裸业务根 ×2 |
| member | /api ×8 · /front ×1 |
| order | /api ×2 · 裸业务根 ×2 |
| payment | /admin ×1 · /api ×2 |
| platform | /admin ×2 · /api ×3 |
| report | /api ×1 · 裸业务根 ×1 |
| subsidy | 裸业务根 ×1 · /api ×1 |

2. **类级基路径跨模块重复**：`/api/platform` 由 `order/PlatformOrderPullController` 与 `platform/PlatformSyncController` 共用。
3. **`/backend/**` 前缀已不存在**：旧文档记载的"早期老接口走 `/backend/`"已不成立，当前 874 个端点中 0 个以 `/backend` 开头；后台页面的接口实际落在 `/api/**`、`/admin/**`、`/sys/**` 与裸业务根。
4. **`@Operation(summary=…)` 已全站中文**：旧文档记载 `ReportEnhancedController` 摘要全为英文，现已是中文（如"查询食材成本报表"）；874 条摘要中含非中文的端点 0 个。
